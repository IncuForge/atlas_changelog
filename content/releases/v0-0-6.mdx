## Rock-solid session stability

Pi sessions are now significantly more reliable on Windows and Linux. Atlas drains Pi's stderr continuously so a full OS pipe buffer can no longer backpressure and stall an active session. When the RPC process does exit unexpectedly, Atlas now captures and reports the tail of Pi's stderr output, making it much easier to diagnose what went wrong.

## Reliable compaction and summarization

Compass now surfaces Pi's summarization retries directly in the interface and clears the compaction indicator when a session fails, so stalled or failed compactions are visible rather than silently blocking context.

Connected to the stability improvements, Compass also now bounds the number of tool records retained per session, preventing unbounded memory growth during long-running conversations.

## Smarter thinking-level handling

Thinking-level options are now read directly from the active Pi runtime instead of being derived from provider catalogue metadata. This means Compass always shows you the thinking and reasoning controls your actual Pi version supports, with no mismatch between what's listed and what's available.

## Package catalog search

Compass settings now include a package catalog search powered by the pi.dev catalogue. You can browse and search the Pi package ecosystem directly from within Atlas, making it easier to discover extensions, skills, themes, and tools without leaving the workspace.

## Refined slash command menu

The slash command menu now limits itself to Pi built-in commands that Compass can faithfully reproduce through JSON-RPC or native desktop equivalents. TUI-only commands that have no Compass equivalent are explicitly rejected, preventing mismatches between the menu and what actually works.

## Polished interface

The onboarding theme preview now matches the brightness of the currently selected theme, so you see an accurate representation of what your terminal will look like. Across Compass settings, spacing has been normalized and the agent watermark has been softened for a cleaner, less distracting appearance.

## Documentation and project maintenance

Atlas documentation, contributor guidance, and repository ignore rules have been updated to reflect current development practices and project structure.
